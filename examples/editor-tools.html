Code as Design Language

The naming conventions themselves are part of the visual identity.

Principle

In this system, code isn't hidden behind the interface—it's embraced as a core aesthetic element. Class names like .mixer-channel and variables like --duration-fast communicate with the same precision as the visual components they define.

This technical transparency reflects Push Record's ethos: tools built for professionals who appreciate the craft beneath the surface.

Naming Convention
.component Block element
.component__element Child element
.component--variant Modifier state
--token-name Design token

Token Glossary

--duration-fast 100ms
--duration-normal 200ms
--ease-out cubic-bezier(0.16, 1, 0.3, 1)
--ease-spring cubic-bezier(0.34, 1.56, 0.64, 1)
--space-4 16px
--radius-sm 4px
--z-modal 50
--blur-md 6px
